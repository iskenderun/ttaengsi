# 의학영어 땡시

`index.html`을 브라우저에서 바로 열면 사용할 수 있는 웹 퀴즈입니다.

## 포함된 기능
- 주차별 누적 범위 선택
- 25초 제한 단답형
- 어휘: 한국어 뜻 -> 영어 어휘
- 어근/접미어/접두어:
  - 영어 풀이 -> 형태소
  - 전체 어휘 빈칸 -> 형태소
- 결과 요약과 오답 확인

## 파일
- `index.html`: 앱 본체
- `styles.css`: 화면 스타일
- `app.js`: 퀴즈 로직
- `quiz-data.js`: 현재 자료에서 생성된 문제 데이터

## 메모
- 어근은 결합모음을 제외한 형태를 기준 정답으로 삼습니다.
- 다만 결합형 표기도 정답으로 인정하도록 설정할 수 있습니다.
- 현재 `4주차`까지 업데이트 완료되었습니다.
- 현재 문서와 `_vocab`에 정의가 없는 항목은 자동으로 제외됩니다.
- 실전 레이아웃 추가 완료.
- 데이터 확인 창에서 단어의 뜻과 형태소 분해를 확인할 수 있습니다.
