# 의학영어 땡시

`index.html`을 브라우저에서 바로 열면 사용할 수 있는 로컬 퀴즈입니다.

## 포함된 기능
- 주차별 누적 범위 선택
- 25초 제한 단답형
- 어휘: 한국어 뜻 -> 영어 어휘
- 어근/접미어/접두어:
  - 영어 풀이 -> 형태소
  - 전체 어휘 빈칸 -> 형태소
- 결과 요약과 오답 확인

## 파일
- `index.html`: 앱 본체
- `styles.css`: 화면 스타일
- `app.js`: 퀴즈 로직
- `quiz-data.js`: 현재 자료에서 생성된 문제 데이터
- `build-data.ps1`: `의학영어(1)` 문서와 `_vocab`에서 데이터를 다시 뽑는 스크립트

## 데이터 다시 생성
PowerShell에서 아래 명령으로 다시 생성할 수 있습니다.

```powershell
Set-Location "C:\Users\emlee\OneDrive\문서\학교\26-1학기\26-1학기\의학영어(1)\ttaengsi-quiz"
& ".\build-data.ps1"
```

## 메모
- 어근은 결합모음을 제외한 형태를 기준 정답으로 삼습니다.
- 다만 입력은 조금 넉넉하게 처리해서 결합형 표기도 정답 인정합니다.
- 현재 `3주차` 문서의 접미어 표는 본문 텍스트가 비어 있어, 연결된 이미지에서 확인 가능한 항목만 보충 반영했습니다.
- 현재 문서와 `_vocab`에 정의가 없는 항목은 자동으로 제외됩니다.
